# Rock Skimmer

Skip stones like it's 1985. A phone-first rock-skimming game: pick one of four 80s kids and one of four places (pond, river, creek, flooded street), swipe up to throw, and let go while the tilt is in the green.

Play it at https://kenburkes.github.io/rock-skimmer/ and use "Add to Home Screen" to install it as an app.
